# EX20 - GitHub Version Control

## Aim

To demonstrate Git and GitHub version control using branches, commits, pull requests, code review, merging, and conflict resolution.

## Modules

### 1. Login Module
Branch:
`login-module`

File:
`login.py`

### 2. Dashboard Module
Branch:
`dashboard-module`

File:
`dashboard.py`

## GitHub Workflow

1. Created a GitHub repository.
2. Created the main branch.
3. Created separate branches for individual modules.
4. Added and committed module changes.
5. Pushed branches to GitHub.
6. Created Pull Requests.
7. Reviewed and merged Pull Requests into main.
8. Created a conflict-demo branch.
9. Created a merge conflict in README.md.
10. Resolved the merge conflict.
11. Committed the resolved changes.
12. Merged the resolved branch into main.

## Files

- README.md
- login.py
- dashboard.py

## Result

The GitHub repository successfully demonstrates branch-based development, Pull Requests, merging, and merge conflict resolution.
